# Native app patterns: what real apps do and how to do it with the kit

The bar is "feels like an app I installed", not "a nice web page". This file compares
each pattern against the apps people already use and lists the details that create the
feeling. Read the section for the pattern you're building.

## The 12 things that make HTML feel like an app

| # | Native behavior | Web-page tell | Kit answer |
|---|---|---|---|
| 1 | Sticky **nav bar**: back button, title, 1–2 actions. Large title that collapses into the bar on scroll (iOS) | Page starts with a badge + h1 + paragraph | `.nav` + `.large-title` (collapse is automatic) |
| 2 | **Bottom tab bar** or a primary action in the thumb zone | Everything reached by scrolling | `.tabbar`, `.bottom-bar` |
| 3 | **Screens and a navigation stack**: tap a row → detail slides in, back slides out | One long page | `.screen` + `data-go` / `IUI.go()` / `IUI.back()` |
| 4 | **Sheets** for create/edit (grabber, Cancel/Save, drag down to dismiss) | Inline forms in the page | `<dialog class="sheet">` + `IUI.sheet()` |
| 5 | **Inset grouped lists**: 44pt+ rows, leading icon tile, trailing value + chevron, hairline separators | Cards with paragraphs | `.list` > `.row` |
| 6 | **Direct manipulation**: swipe a row to delete, long-press/handle to reorder, swipe between pages, drag the sheet | ↑ ↓ ✕ buttons | `.row[data-swipe]`, `.list[data-reorder]`, `.pager` |
| 7 | **Native controls**: switch, segmented control, stepper (− 2 +), sliders, pickers | Checkboxes, chip rows, bare number inputs | `.switch`, `.seg`, `.stepper`, native `date`/`color` inputs |
| 8 | **Feedback**: pressed state on touch-down, haptic tick, snackbar with Undo, confirmation as an action sheet | Hover styles, `confirm()` (blocked in artifacts) | `:active` states, `IUI.haptic()`, `IUI.toast(msg, undo)`, `IUI.confirm()` |
| 9 | **Real icons** (SF Symbols / Material Symbols), one weight, one size | Emoji in buttons | `IUI.icon(name)` / `<svg class="i"><use href="#i-name"/></svg>` |
| 10 | **System typography**: 17px body, 34px bold large title, 13px footnotes, no font downloads | Web fonts, 15px body | system font stack, iOS type scale |
| 11 | **Tint color**: one brand hue on every interactive element, nothing else colored | Many accent colors | `--tint-l` / `--tint-d` per app |
| 12 | **State survives**: reopening returns to the same screen, step and data | Resets on reload | `IUI.store` for data + `IUI.go` remembers screen/step |

Plus the hygiene that native apps get for free: no double-tap zoom delay (`touch-action:
manipulation`), no blue tap flash, no input zoom (inputs ≥16px), no text selection on
controls, no rubber-band scroll inside sheets and pagers (`overscroll-behavior: contain`),
safe-area padding on fixed bars, dark mode, and Reduce Motion.

## Follow: step-through guides
**Reference apps:** IKEA assembly instructions, LEGO Builder, NYT Cooking / Paprika
"cook mode", How to Make Origami, Apple Fitness+ workout steps.

| What they do | Why | Kit |
|---|---|---|
| Full-screen **pager**, one step per page, swipe follows the finger and snaps | One idea per screen; hands are busy | `.pager` (native scroll-snap) |
| **Segmented progress bar** at the top (LEGO, Stories) and "Step 4 of 9" | Shows where you are without dots that are too small to tap | `.pager-progress`, generated |
| Big **Next** button in the bottom bar; Back is smaller | Thumb zone; forward is the common action | `.bottom-bar` generated by the pager |
| **Diagram first**, large, wordless where possible (IKEA); short verb-first caption | Diagrams cross languages and skill levels | `.paper` figure fills the page width |
| **Tap the diagram to zoom** (pinch or double-tap) | Small parts | `data-zoom` on the figure opens the zoom viewer |
| **"You need" chips for this step** (LEGO parts, recipe ingredients per step) | No scrolling back to the list | `.chips` row inside the page |
| **Overview grid** of all steps to jump (LEGO "all steps", recipe step list) | Resume or re-check | nav action → sheet with step thumbnails/titles |
| **Keep screen awake** while following (cooking apps) | Hands are dirty | `IUI.keepAwake(true)` on start (tolerates refusal) |
| Completion screen with a clear "done" moment | Closure | last page = done state + optional checklist |

## Edit a plan: living itinerary
**Reference apps:** Wanderlog, Google Maps saved lists, Apple Maps Guides, TripIt, Citymapper.

| What they do | Kit |
|---|---|
| **Map on top, list below**, linked both ways: tap a row to highlight its pin, tap a pin to scroll to its row | `IUI.map()` + `selected` state |
| **Day switcher** as a segmented control or horizontal day chips under the nav bar | `.seg` / `.chips` sticky under `.nav` |
| Rows: numbered pin, name, time, duration; **travel time between rows** as a small connector ("12 min walk") | `.row` + `.leg` connector |
| **Drag handle to reorder**, **swipe left to delete**, Undo snackbar | `.list[data-reorder]`, `.row[data-swipe]`, `IUI.toast` |
| **"+ Add place"** opens a search sheet with suggestions | `.sheet` with a search field and a suggestion list |
| Totals (time, distance, finish time) update live in a summary strip | `.summary` strip |
| Real geography: pins at real coordinates, scale bar, north up | `IUI.map` takes lat/lng and draws a scale bar |

## Preview: live configurator (paint, furniture, outfit)
**Reference apps:** Dulux Visualizer, Benjamin Moore Color Portfolio, Sherwin-Williams
ColorSnap, IKEA Kreativ.

| What they do | Kit |
|---|---|
| **Preview fills the top half**, stays visible (sticky) while you pick | `.preview` sticky block under the nav bar |
| **Swatch strip** at the bottom, families as a segmented control | `.seg` + `.swatches` scroller |
| **Color detail sheet**: name, code, LRV (light reflectance), coordinating colors | `.sheet` with `.kv` rows; `IUI.color.lrv()`, `IUI.color.harmony()` |
| **Lighting/context toggle** (daylight, warm bulb, north light) | `.seg` driving an overlay |
| **Favorites** (heart) and **compare two** side by side | `.btn-icon` toggle + split preview |
| **Paint calculator**: wall size → litres and tins | `.list` with `.stepper` fields |

## Track: health and habit trackers
**Reference apps:** Apple Health, Google Fit, Streaks, Bearable.

| What they do | Kit |
|---|---|
| **Summary** of metric cards in a 2-column grid: icon + colored metric name, big value, unit, tiny sparkline, chevron | `.metric` cards in `.grid-2` |
| Tap a card → **detail screen**: D / W / M segmented control, chart you can **scrub with a finger**, highlight sentence, "Show all data" list | `.screen` + `.seg` + `IUI.chart` (scrub built in) |
| **"Add Data"** as a nav-bar action opening a sheet with steppers and a date picker | `.nav` action + `.sheet` + `.stepper` |
| Rings or progress bars against goals | `IUI.ring()` |
| Swipe to delete an entry in the data list | `.row[data-swipe]` |

## Plan with time: trip / event plan
**Reference apps:** Google Travel, Airbnb trips, TripIt.
Hero with dates, day chips, timeline per day, booking checklist, budget estimate.
Use `.seg`/chips for days, `.timeline` rows, `.list` checklists using `.check` rows, and a
budget sheet with a `.stepper` for travelers.

## Decide / understand / calculate
**Reference apps:** Apple Compare (product pages), Wirecutter, Calculator apps, Brilliant.
Side-by-side `.compare` columns with sticky headers; `.seg` to switch what matters;
explorables put the diagram on top and one slider under it, so the change happens in
view; calculators use a large output on top and `.list` input rows below.
